# Что определяет измеренную калибровку моделей отслеживания знаний

Репозиторий воспроизведения к статье. Здесь лежит всё, из чего собрана каждая
таблица и каждый рисунок статьи: сохранённые сводки, код, который их считает, и
генераторы, печатающие таблицы и рисунки заново.

Текста статьи здесь нет — он выходит в журнале, и права на опубликованную версию
принадлежат ему. Это ничего не отнимает у проверки: возьмите таблицу из статьи,
напечатайте её же командой ниже и сравните. Все десять таблиц и все три рисунка
собираются из того, что лежит в `artifacts/`.

## Что внутри

    ktx/         5 модуля: метрики, способы поправки, процедуры значимости,
                 быстрый кластерный бутстрап, восстановление принадлежности строк
    scripts/     13 сценариев: пересчёт калибровочных таблиц, шесть
                 расчётов статьи, генераторы таблиц и рисунков
    tests/       2 файла тестов
    artifacts/   55 таблиц и один файл со скалярными величинами
    paper/       три рисунка статьи в двух форматах

## Быстрая проверка

    pip install -e .
    python -m pytest tests -q
    python -m scripts.make_c4_tables

Первая команда ставит пакет, вторая проверяет, что быстрый кластерный бутстрап
совпадает с эталонной реализацией при том же посеве, третья печатает все десять
таблиц статьи из сохранённых сводок. Ни одно число в них не набрано руками.

Скалярные величины, на которые ссылается текст статьи — числа ячеек, крайние
значения, доли, — лежат отдельно в `artifacts/cross_dataset/c4_numbers.json` и
пересчитываются той же командой. Сверять прозу статьи с ними можно по имени
величины, не открывая код.

Рисунки строятся оттуда же, все три:

    python -m scripts.make_c4_figures

Второй рисунок — согласие вероятности с частотой до поправки и после — строится по
самим вероятностям, а не по сводкам. Чтобы он воспроизводился и здесь, посчитанные
корзины сохранены таблицей `c4_reliability_bins.csv`: в ней на строку приходится
одна корзина одной панели — среднее предсказание, наблюдённая доля верных ответов и
число строк. Там, где файлы предсказаний есть, сценарий пересчитывает эту таблицу и
строит рисунок по ней же; здесь он строит его из готовой таблицы и говорит об этом.

## Чего здесь нет

Файлов предсказаний моделей (около 1,6 ГБ) и сырых наборов данных. Поэтому
сценарии счёта в этом репозитории не запускаются и приведены ради проверяемости —
по ним видно, как получены таблицы:

    scripts/backfill_concept_groups.py        нужны файлы предсказаний
    scripts/verify_concept_groups.py          нужны файлы предсказаний
    scripts/deep_calibration_5fold.py         нужны файлы предсказаний
    scripts/deep_calibration_5fold_qlvl_v4.py нужны файлы предсказаний
    scripts/classical_calibration_5fold.py    нужны файлы предсказаний
    scripts/c4_significance.py                нужны файлы предсказаний
    scripts/c4_path.py                        нужны файлы предсказаний
    scripts/c4_subgroups.py                   нужны файлы предсказаний
    scripts/c4_concept_aware.py               нужны предсказания и последовательности
    scripts/c4_binning.py                     нужны файлы предсказаний
    scripts/c4_aggregate_ci.py                нужны файлы предсказаний

Всё, что они считают, лежит в `artifacts/` готовыми таблицами, и вся дальнейшая
цепочка — таблицы и рисунки — работает от них.

Обучение моделей в этот репозиторий тоже не входит: матрица из семи наборов
данных, четырёх нейросетевых моделей и пяти разбиений обучалась 27,6 часа на
графическом ускорителе, и её результат — те самые файлы предсказаний.
